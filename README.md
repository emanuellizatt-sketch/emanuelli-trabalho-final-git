        Site Sotam

--Sobre o projeto

O projeto consiste em uma página web dedicada ao cantor e rapper brasileiro Sotam.

A proposta é criar uma apresentação simples e visualmente organizada, permitindo que o visitante conheça o artista, veja algumas de suas músicas e acesse suas plataformas digitais.

--Funcionalidades
- Página inicial com apresentação do artista;
- Seção "O artista", com informações sobre Sotam e sua trajetória;
- Seção de Músicas em destaque;
- Botões "Ouvir" que direcionam para o Spotify;
- Seção de contato com links para redes sociais;
- Menu de navegação entre as seções;
- Layout adaptado para dispositivos menores.

--Músicas em destaque
O site apresenta as seguintes músicas:
- Bloco dos Apaixonados
- Sem Pausa
- Sinceramente
- Foi Assim
- 3AM (PXT4 RASA)
- Cura
Os botões de cada música utilizam JavaScript para abrir os respectivos links no Spotify.

        Tecnologias utilizadas

--HTML
Utilizado para criar a estrutura e organizar o conteúdo da página.

--CSS
Utilizado para estilização, cores, espaçamento, layout, efeitos de interação e responsividade.

--JavaScript
Utilizado para adicionar interatividade aos botões de músicas e configurar os links das redes sociais.

--Design
O site utiliza uma identidade visual predominantemente escura, com fundo preto e tons de cinza.

A página inicial possui uma área de destaque com o nome do artista, uma breve descrição e uma imagem em preto e branco.

As seções de informações utilizam cards e efeitos de `hover` para melhorar a interação com o usuário.

--Responsividade
O site possui regras específicas para telas menores utilizando `@media (max-width: 768px)`, adaptando o menu, os textos e o conteúdo para dispositivos móveis.
